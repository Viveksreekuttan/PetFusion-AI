# 🐾 PetFusionAI

An AI-powered pet healthcare and stray animal monitoring platform developed using Flutter, Firebase, Artificial Intelligence, and OpenStreetMap.

PetFusionAI helps pet owners, animal rescue teams, and veterinary organizations manage pet healthcare, monitor stray dog activity zones, analyze symptoms using AI, and provide nutrition & diet recommendations for pets.

# 📌 Overview

PetFusionAI is a smart veterinary and stray animal management system designed to improve pet healthcare and support animal welfare initiatives.

The platform combines:
- AI-powered symptom analysis
- Nutrition & diet recommendation system
- Stray dog area detection using OpenStreetMap
- Real-time pet healthcare monitoring
- Cloud-based Firebase backend
- Cross-platform Flutter application support

The project focuses on both domestic pet care and public animal safety management.

# 🗺 OpenStreetMap Based Stray Dog Area Detection

PetFusionAI integrates OpenStreetMap to identify and monitor stray dog populated areas.

### Features Include:
- Mapping stray dog activity zones
- Detecting high-risk stray animal regions
- Community reporting system
- Location tagging for stray sightings
- Real-time visualization of stray hotspots
- Support for animal rescue organizations

### Use Cases:
- Public safety awareness
- Animal rescue coordination
- Veterinary outreach planning
- Stray dog population monitoring
